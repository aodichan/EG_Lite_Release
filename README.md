## EG_Lite_V1.1.0.0

### 产品简介

1. EG_Lite 是一款面向 EG 系列设备的轻量级上位机工具，用于设备调试、参数配置和功能验证。
2. 软件支持通过串口连接设备，完成设备通信、状态查看、参数读取和参数写入等常用操作。
3. 软件使用 Excel 配置文件管理不同型号的 APP、DID、CFG 参数，方便不同产品型号快速切换。
4. 内置 `cfg` 配置目录，启动后可直接从配置列表中选择对应型号，无需手动查找配置文件。
5. 支持导入本地 Excel 配置文件，适合临时调试、验证新配置或使用未发布的配置文件。
6. CFG 参数支持按配置表展示、读取、修改和写入，便于快速定位和调整设备参数。
7. 软件提供升级相关功能，可根据设备和当前配置执行对应的升级或维护操作。
8. 启动时会检查本地配置文件，确保程序目录下存在可用的 `cfg` 配置。
9. 适用于研发调试、生产验证、售后维护和现场问题排查等场景。

### 基本使用

1. 安装或解压 EG_Lite 后，运行 `EG_Lite.exe` 启动软件。
2. 在启动页选择需要使用的型号配置，也可以通过本地文件方式选择 Excel 配置。
3. 进入主界面后，根据设备连接情况选择串口并建立通信。
4. 需要读取设备参数时，进入对应页面执行读取操作，并根据界面结果确认当前设备状态。
5. 需要修改设备参数时，先确认配置项含义和取值范围，再写入设备。
6. 使用升级或维护功能前，请确认设备供电、通信连接和目标文件正确。
7. 如果启动时提示配置更新，建议同步最新配置后再进行调试或写入操作。
8. 如果启动时提示软件更新，可根据更新来源选择下载或安装新版本。

### 使用注意

1. 写入参数前请确认当前连接设备型号与所选配置一致。
2. 写入 CFG 或执行升级操作时，请勿断开设备连接或关闭软件。
3. 本地自定义 Excel 配置仅建议用于调试验证，正式使用建议选择发布目录中的配置。
4. 如遇到配置列表为空，请确认程序目录下存在 `cfg` 文件夹以及有效的 `.xlsx` 配置文件。
5. 如遇到通信失败，请先检查串口号、波特率、设备供电和线束连接。
