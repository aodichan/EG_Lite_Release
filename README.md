# EG_Lite 上位机更新说明

## EG_Lite_V1.1.0.0

### 功能优化

1. 软件更新支持双服务器来源：优先检查公共技术空间，公共技术空间无法访问时自动检查 GitHub 备用服务器。
2. Excel 配置更新支持双服务器来源：优先检查公共技术空间 `cfg` 文件夹，无法访问时自动检查 GitHub `cfg` 文件夹。
3. 公共技术空间的 Excel 配置目录已调整为 `cfg` 文件夹，与 GitHub 目录结构保持一致。
4. 如果公共技术空间和 GitHub 都无法访问，启动时不会弹出软件更新或 Excel 配置更新提示。

## EG_Lite_V1.0.8.6

### 新增功能

1. 启动时支持检查软件新版本，发现服务器有更新时提示用户。
2. 启动时支持检查服务器 Excel 配置更新，本地 `cfg` 可同步最新配置。
3. 上位机配置入口改为优先使用本地 `cfg` 目录中的 Excel 配置。

### 功能优化

1. Excel 配置更新改为按文件内容 hash 判断，避免相同文件因名称或修改时间变化误提示更新。
2. Excel 配置文件匹配时会忽略文件名末尾的 6 位校验码，减少同一配置重复提示更新。
3. 无法访问服务器时，不再弹出软件更新或 Excel 更新提示。
4. 软件更新提示根据当前运行形式区分处理方式，减少误操作。

### Bug 修复

1. 修复 CFG 中 `s8` 数据读出错误的问题。
2. 修复 CFG 中 `s8` 数据写入范围未限制的问题。
3. 修复相同 Excel 文件因修改时间不同被误判为需要更新的问题。
